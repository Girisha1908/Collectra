# 🖥️ Collectra — Frontend Application

This folder contains the frontend application for the **Collectra** package management platform, built using Next.js, Tailwind CSS, TypeScript, and shadcn/ui.

## 🚀 Getting Started

To run the frontend locally:
1. Ensure the backend API server is running (see the root [README.md](../README.md)).
2. Make sure you have created your `.env` file with `NEXT_PUBLIC_API_URL`.
3. Install dependencies and start the development server:
   ```bash
   npm install
   npm run dev
   ```

For detailed configuration, environment setups, and deployment steps, please refer to the main repository documentation:
👉 **[Root README.md](../README.md)**
